- All tracker data (sessions, topics, questions) lives in `src/lib/tracker-store.tsx` and persists to localStorage — the app is offline-first with no backend.
- Offline/installable support is generated by `vite-plugin-pwa` and registered only through `src/lib/register-sw.ts`, which refuses dev/preview contexts.
- Native Android build uses Capacitor (`capacitor.config.ts`) wrapping the published URL — the SSR app has no static bundle to ship inside the APK.
